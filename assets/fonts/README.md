# Local UI fonts

Noto Sans (SIL Open Font License 1.1), sourced from Google Fonts.
Official source: https://github.com/google/fonts/tree/main/ofl/notosans
License: OFL-NotoSans.txt

Four static weights (400, 500, 600, 700), about 39 KB each. Subsets contain the Kazakh, Russian and English alphabets, digits, tenge symbol and characters used by the current site. If new scripts are added, regenerate the subsets. CSS family alias: Birge Sans; original font names and license are preserved.

Kazakh letters ӘәҒғҚқҢңӨөҰұҮүҺһІі and ₸ verified in each file through its cmap table. Regular and semibold are preloaded; font-display: swap keeps text visible while loading. No external font request is made by the site.
